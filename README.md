# App Android para explorar películas con la API de [TMDB](https://www.themoviedb.org/).
Hecho en compose y no xml

## Configuración
1. Cloná el repositorio.
2. No es necesario agregar api key.
4. Abrí el proyecto en Android Studio y ejecutalo.

## Funcionalidades
- Películas populares con paginado infinito
- Búsqueda de películas
- Detalles: géneros, duración, sinopsis, trailer (se abre en YouTube) y películas similares
- Watchlist guardada en el dispositivo
- Errores en pantalla con botón para reintentar
- Tema claro y oscuro, e idioma según el del sistema
